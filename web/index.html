РАСКЛАДКА

КАК ПОЛЬЗОВАТЬСЯ
  1. Сначала подключи устройства.Открой адрес из окна сервера на планшетах и компьютерах.
  2. Назначь игроков.В шестерёнке выбери разные слоты P1–P4. Для клавиатуры первого игрока планшету обычно нужен P2.
  3. Главный компьютер.В WG HOST CONTROL нажми «Свернуть панель и запустить». Панель вернёт фокус игре сама. F10 освобождает ввод.
  4. Другой компьютер.В браузере нажми «Захватить мышь». WASD станет левым стиком, мышь — правым. Esc освобождает курсор.
  5. Запусти игру последней.Некоторые игры находят контроллеры только во время запуска.
  6. Настрой вид.Темы, стили, формат экрана и редактор раскладки находятся в шестерёнке.
