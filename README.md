# Wi‑Fi Gamepad

Версия 3.2 — до четырёх независимых устройств: планшетов, других компьютеров и самого компьютера-сервера. Панель хоста теперь сама сворачивается и возвращает фокус игре, содержит редактор раскладки и отдельный QR-код подключения.

Короткие касания цифровых кнопок теперь удерживаются минимум 90 мс, чтобы игры не пропускали быстрые нажатия START/Menu и других кнопок.

Планшет становится настраиваемым Xbox 360-контроллером для Windows. Интерфейс открывается в браузере, а управление передаётся только внутри локальной сети через WebSocket.

## Первый запуск

1. Установите **Python 3.11+** с [python.org](https://www.python.org/downloads/windows/). При установке отметьте `Add Python to PATH`.
2. Запустите `install-driver.bat`, скачайте `ViGEmBus_Setup_x64.msi` с официальной страницы и установите драйвер. После установки лучше перезагрузить ПК.
3. Запустите `start.bat`. В первый раз зависимости установятся автоматически.
4. Если Windows спросит про брандмауэр, разрешите Python доступ **только к частным сетям**.
5. На планшете или другом компьютере в той же Wi‑Fi-сети отсканируйте QR-код либо откройте сетевой адрес из окна.
6. Вместе с сервером автоматически откроется окно `WG HOST CONTROL` для клавиатуры и мыши главного компьютера. QR-код и копирование сетевого адреса находятся во вкладке `ПОДКЛЮЧЕНИЕ`.

Компьютер должен увидеть новый `Controller (XBOX 360 For Windows)`. Проверить его можно через `Win + R` → `joy.cpl`.

## Управление и настройка

- Все параметры находятся под кнопкой-шестерёнкой: устройство, ввод, экран, темы и редактор раскладки.
- Маленькая кнопка `i` открывает краткий встроенный туториал.
- В разделе `СТИЛЬ` → `ОТКРЫТЬ РЕДАКТОР` включается настройка раскладки.
- Перетащите элемент, чтобы изменить положение.
- Потяните квадрат в правом нижнем углу элемента, чтобы изменить размер.
- Выберите элемент и поменяйте его действие в нижней панели.
- `+ ЭЛЕМЕНТ` добавляет кнопку, стик или D-pad.
- `СБРОС` возвращает стандартную раскладку.
- Раскладка сохраняется в браузере планшета автоматически.

Для игры нажмите `ГОТОВО`, затем кнопку полного экрана. Планшет лучше повернуть горизонтально.

### Компьютер как джойстик

- На главном компьютере используйте нативное окно `WG HOST CONTROL`, а не браузерный захват мыши.
- Выберите свободный P1–P4 и нажмите `СВЕРНУТЬ ПАНЕЛЬ И ЗАПУСТИТЬ`. Панель свернётся, вернёт фокус предыдущему окну игры и включит ввод после выбранной задержки.
- `F9` оставлен как дополнительная глобальная клавиша, но больше не требуется для обычного запуска.
- `F10` в любой момент выключает перехват и возвращает обычную клавиатуру и мышь. Это аварийная клавиша, которую стоит запомнить.
- Пока режим активен, исходные клавиатура и мышь блокируются: игра получает только виртуальный контроллер и не управляет вторым персонажем одновременно.
- `WASD` — левый стик, мышь — правый стик, стрелки — D-pad.
- `Space` — A; `E`, `Q`, `R` — B, X, Y; `Enter` — START; `Backspace` — BACK.
- Левая и правая кнопки мыши — RT и LT. Чувствительность мыши регулируется в том же разделе.
- Для другого компьютера по-прежнему доступен браузерный режим из вкладки `ВВОД`; он работает, пока вкладка остаётся активной.

### Настройка управления хоста

- Во вкладке `УПРАВЛЕНИЕ` можно переназначить левый стик, A/B/X/Y, бамперы, триггеры, START/BACK, L3/R3 и D-pad.
- Нажмите на текущую клавишу возле действия, затем нажмите новую. `F9` и `F10` зарезервированы.
- Для левой, правой, средней и двух боковых кнопок мыши действие выбирается отдельно.
- Слот, чувствительность, задержка, блокировка исходного ввода и вся раскладка сохраняются между запусками.
- Кнопка сброса возвращает стандартную схему WASD + мышь.

### Несколько устройств и игроки

- Один адрес можно открыть одновременно на четырёх планшетах или компьютерах, включая компьютер-сервер.
- Каждое устройство получает отдельный виртуальный Xbox 360-контроллер.
- Шестерёнка открывает список устройств, позволяет переименовать текущий экран и выбрать слот P1–P4. В списке видно, используется сенсор или клавиатура с мышью.
- Если клавиатура управляет первым персонажем, назначьте планшету `P2`. Приложение оставит P1 свободным и отправит команды планшета только во второй виртуальный контроллер.
- Занятый другим устройством слот выбрать нельзя. При отключении соответствующий контроллер немедленно отпускает все кнопки.

Игра должна сама поддерживать локальный мультиплеер и раздельные контроллеры. Некоторые игры намеренно объединяют клавиатуру и первый геймпад — поэтому для планшета в таких случаях нужен P2.

### Экран и оформление

- Вкладка `ЭКРАН`: Auto, 16:9, 16:10 или 4:3; заполнение 70–100%; безопасные поля 0–8%.
- `ТЕМА`: Terminal, Ice, Amber или Violet.
- Стили элементов: Soft, Pixel или Glass.
- Раскладка, экран, тема, стиль, имя устройства и игровой слот сохраняются отдельно на каждом устройстве.

## Безопасность и ограничения

- При каждом запуске создаётся новый случайный ключ. Без него страница не может управлять геймпадом.
- Сервер слушает локальную сеть; не перенаправляйте порт `8765` на роутере в интернет.
- При потере связи сервер автоматически отпускает все кнопки через 0,75 секунды.
- Качество управления зависит от Wi‑Fi. Для минимальной задержки лучше использовать сеть 5 ГГц и находиться рядом с роутером.
- Сенсорный экран не заменяет физические стики по точности и тактильной отдаче, но подходит для неторопливых игр, эмуляторов и собственных раскладок.

## Диагностика

- **Страница не открывается:** проверьте одну Wi‑Fi-сеть, частный тип сети Windows и разрешение брандмауэра.
- **В окне появляются обрывки команд вроде `ython` или `is not recognized`:** это ошибка старой версии запускных файлов. Скачайте свежий архив и распакуйте его в новую папку.
- **Страница открылась, игра не видит контроллер:** установите ViGEmBus и перезагрузите ПК; затем проверьте `joy.cpl`.
- **Нужно проверить интерфейс без драйвера:** запустите `test-mock.bat`.
- **Игра запущена от администратора:** обычно это не мешает виртуальному контроллеру, но перезапустите `start.bat` после установки драйвера.
- **Панель хоста не появилась:** закройте сервер и снова запустите `start.bat`; он автоматически установит недостающий компонент `pynput`.
- **Ввод не возвращается:** нажмите `F10`. При закрытии панели или потере связи все кнопки также автоматически отпускаются.
- **Игра всё равно не получает фокус:** перед нажатием кнопки запуска один раз откройте игру, затем вернитесь в панель. Она запомнит последнее активное окно и восстановит его.
